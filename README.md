# Summer Palace 360° Tour Tutorial
An HTML tutorial introducing a 360° tour of the Summer Palace.

## Overview
This repository contains the Summer Palace 360° Tour Tutorial and
its supporting project files.

## Getting Started
1. Download or clone this repository.
2. Locate the tutorial HTML file.
3. Open the file in a web browser.

Keep any accompanying folders alongside the HTML file so that
relative links to images, scripts, and other assets remain valid.
